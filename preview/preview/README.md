# موقع عزيز المالكي: دليل الاستخدام

الموقع منشور على GitHub Pages: https://azizalmalki.github.io

## كيف يشتغل الموقع

- كل المحتوى في ملف واحد هو `data/site.json`، ويشمل الأعمال والمسيرة والشهادات والنبذة وروابط التواصل.
- عند كل نشر من لوحة الإدارة، تُبنى كل صفحات الموقع من جديد كصفحات HTML جاهزة. لذلك كل كلمة موجودة داخل الصفحة نفسها، ومحركات البحث وأدوات الذكاء الاصطناعي تقرؤها حتى بدون JavaScript.
- الصفحات المبنية:
  - الرئيسية: `/` و`/en/`
  - صفحة «عن عزيز المالكي»: `/about/` و`/en/about/`
  - صفحة مستقلة لكل عمل: `/work/<اسم-العمل>/` و`/en/work/<اسم-العمل>/`
  - إضافة إلى `sitemap.xml` و`llms.txt`
- أي عنصر **غير منشور** أو **فاضي** ما يظهر للزوار. ولما تخفي عملًا أو تحذفه، تنحذف صفحته تلقائيًا.

## إضافة وتعديل المحتوى (بدون برمجة)

افتح لوحة الإدارة: `https://azizalmalki.github.io/admin/`

1. **الأعمال:** اضغط «+ إضافة عمل جديد»، ثم عبّ:
   - الاسم والنوع والجهة ودورك، بالعربي والإنجليزي
   - **القسم في الموقع:** التقديم التلفزيوني، أو تقديم الفعاليات، أو المقابلات، أو الصحافة، أو الإنتاج، أو الإعلام والتسويق
   - **طبيعة العمل:** برنامج تلفزيوني، أو برنامج رقمي، أو **فعالية**. اختيار «فعالية» يعرّفها لمحركات البحث كحدث، وتقدر تكتب مكانها وتاريخها.
   - **المصادر الخارجية:** روابط تثبت العمل، مثل الحلقة على يوتيوب أو خبر عن الفعالية. هذه أهم شيء لمصداقيتك عند محركات البحث.
   - **الفيديوهات:** العنوان والوصف والمدة وتاريخ النشر الأصلي، والنص المكتوب للحلقة إذا توفر.
   - **منشور:** يظهر العمل للزوار. **مميز:** يظهر في «أعمال مختارة».
2. **البيانات الأساسية:**
   - الصفة المهنية، والنص التعريفي، والنبذة المختصرة، ومجالات الخبرة
   - روابط التواصل: لينكدإن ويوتيوب
   - رفع الفيديو التعريفي والسيرة الذاتية
   - رموز إثبات الملكية لـ Google وBing
3. **الإعلام والتسويق / المسيرة / نبذة وتعاون:** تعديل مباشر للنصوص.
4. **الإحصائيات:** الزيارات والإعجابات ومشاهدات كل عمل. الأرقام تظهر لك أنت فقط.
5. اضغط **«نشر التعديلات»**. يُحفظ كل شيء في خطوة واحدة، ويظهر في الموقع خلال دقيقة أو دقيقتين.

## ربط اللوحة (مرة وحدة)

اللوحة تحتاج «مفتاح» من GitHub يُحفظ في متصفحك فقط، ولا يُكتب داخل ملفات الموقع:

1. افتح https://github.com/settings/personal-access-tokens/new
2. Repository access: Only select، ثم اختر `azizalmalki.github.io`
3. Permissions، ثم Contents: **Read and write**
4. اضغط Generate token، والصق المفتاح في اللوحة.

## الفهرسة ومحركات البحث

- `robots.txt` يسمح لكل محركات البحث وأدوات البحث بالذكاء الاصطناعي، مثل Googlebot وBingbot وOAI-SearchBot وClaude-SearchBot وPerplexityBot.
- برامج تدريب الذكاء الاصطناعي، مثل GPTBot وClaudeBot وGoogle-Extended، **غير ممنوعة**، وهذا هو الوضع الافتراضي. إذا تبي تمنع التدريب فقط بدون ما يتأثر ظهورك في البحث، احذف علامة `#` من الأسطر الجاهزة داخل الملف.
- النسخة التجريبية `/preview/` عليها وسم `noindex`. وهي **غير ممنوعة** في robots.txt عن قصد، لأن المحرك ما يقدر يقرأ وسم noindex إلا إذا سُمح له بالدخول.

## ملفات المشروع

| الملف | وظيفته |
|---|---|
| `data/site.json` | كل المحتوى |
| `assets/render.js` | يبني كل الصفحات من المحتوى، في اللوحة وفي أداة البناء |
| `assets/site.css` | نظام التصميم: الألوان والخطوط والمسافات |
| `assets/site.js` | التفاعل فقط: القائمة، والحركة، وتكبير الصور، والعدادات |
| `index.html`، `about/`، `work/`، `en/` | الصفحات المبنية. لا تعدّلها يدويًا، لأنها تُبنى من جديد عند كل نشر |
| `img/` | الصور بصيغة WebP بأكثر من مقاس، وصورة المعاينة `og-image.jpg` |
| `admin/` | لوحة الإدارة، وهي مخفية عن محركات البحث |
| `robots.txt`، `sitemap.xml`، `llms.txt` | ملفات الفهرسة |
