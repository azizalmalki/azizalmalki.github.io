# موقع عزيز المالكي — دليل الاستخدام

الموقع منشور على GitHub Pages: https://azizalmalki.github.io

## كيف يشتغل الموقع

- كل محتوى الموقع (الأعمال، المسيرة، الشهادات، النبذة، روابط التواصل) محفوظ في ملف واحد: `data/site.json`.
- الصفحة العربية `index.html` والإنجليزية `en/index.html` تقرأ هذا الملف وتعرض المحتوى.
- أي عنصر **غير منشور** أو **فاضي** ما يظهر للزوار. ما فيه أي «قريبًا» أو «مكان فاضي» في الموقع.

## إضافة وتعديل المحتوى (بدون برمجة)

افتح لوحة الإدارة: `https://azizalmalki.github.io/admin/`

1. **الأعمال:** «+ إضافة عمل جديد»، عبّي الاسم والنوع والجهة ودورك بالعربي والإنجليزي، أضف الغلاف والصور والفيديو.
   - **منشور:** يظهر للزوار. شيل العلامة لإخفاء العمل بدون حذفه.
   - **مميز:** يظهر في «أعمال مختارة» أعلى الموقع.
   - **أمام الكاميرا:** يضيف علامة تفرّق أعمال التقديم عن أعمال الإنتاج.
   - الأسهم ↑↓ ترتّب الأعمال.
2. **البيانات الأساسية:** النص التعريفي، رابط لينكدإن، رفع الفيديو التعريفي، رفع السيرة الذاتية PDF.
   زر الفيديو التعريفي وزر السيرة الذاتية ما يظهرون إلا بعد رفع الملف ووضع علامة «إظهار».
3. **الإعلام والتسويق / المسيرة / نبذة وتعاون:** تعديل مباشر للنصوص.
4. **الإحصائيات:** الزيارات والإعجابات والضغطات على التواصل ومشاهدات كل عمل. الأرقام لك أنت بس.
5. اضغط **«نشر التعديلات»**. التعديل يظهر في الموقع خلال دقيقة تقريبًا.

الصور تتحول تلقائيًا إلى WebP بمقاسين (480 و900 بكسل) قبل الرفع. الفيديو حتى 45 ميجا.

## ربط اللوحة (مرة وحدة)

اللوحة تحتاج «مفتاح» من GitHub يُحفظ في متصفحك فقط، ولا يُكتب داخل ملفات الموقع:

1. https://github.com/settings/personal-access-tokens/new
2. Repository access: Only select → `azizalmalki.github.io`
3. Permissions → Contents: **Read and write**
4. Generate token، والصقه في اللوحة.

## ملفات المشروع

| الملف | وظيفته |
|---|---|
| `index.html` / `en/index.html` | الصفحتان (العربية/الإنجليزية) مع بيانات SEO والمعاينة |
| `data/site.json` | كل المحتوى |
| `assets/site.css` | نظام التصميم (الألوان، الخطوط، المسافات) |
| `assets/site.js` | عرض المحتوى، دراسات الحالة، الحركة، العدادات |
| `assets/fonts/` | خط ثمانية (عادي، عريض، أسود) |
| `img/` | الصور بصيغة WebP بأكثر من مقاس، وصورة المعاينة `og-image.jpg` |
| `admin/` | لوحة الإدارة (مخفية عن محركات البحث) |
| `robots.txt` / `sitemap.xml` | الفهرسة في محركات البحث |

## Google Search Console (يحتاج تدخلك)

1. ادخل https://search.google.com/search-console وسجّل بحساب Google الشخصي.
2. Add property → **URL prefix** → `https://azizalmalki.github.io/`
3. اختر طريقة التحقق **HTML tag**، وانسخ قيمة `content` وأرسلها لي، أضيفها في رأس الصفحة.
4. بعد التحقق: Sitemaps → أضف `sitemap.xml`.
